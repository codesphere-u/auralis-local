Auralis Documentation

Requires Node.js 22.12+ and Ollama on Apple Silicon (or Linux).

1. Mac Setup

git clone https://github.com/codesphere-u/auralis-local.git
cd auralis-local
ollama pull qwen3.5:4b
npm install
npm run dev

2. Production Server

npm run build
npm start

Serves both the built React UI and protected API at http://127.0.0.1:4317.

3. Knowledge Base & PDF

Use the Knowledge view or POST /api/knowledge/documents to index Markdown, source files, and PDFs with #Lstart-Lend citations.

4. Voice Room

npm run voice:setup
npm run build
npm run talk

5. Benchmarks & Checks

npm run check
npm run benchmark -- --local-only
npm run benchmark:memory
