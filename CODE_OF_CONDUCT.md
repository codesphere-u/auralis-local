# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, and harassment-free engineering community for everyone contributing to or using Auralis.

## Expected Behavior

- **Be respectful and constructive**: Focus critiques on code, architecture, security boundaries, and reproducible measurements rather than individuals.
- **Be honest about capabilities and benchmarks**: Do not fabricate benchmark numbers, hardware claims, or security guarantees. Always document test conditions and limitations clearly.
- **Respect user privacy and agency**: Never introduce hidden telemetry, background network calls, or unapproved local file/tool mutations.

## Unacceptable Behavior

- Harassment, personal attacks, or derogatory language of any kind.
- Publishing others' private information without explicit permission.
- Submitting intentionally obfuscated code, backdoors, or bypasses of loopback/approval security controls.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, and pull requests that do not align with this Code of Conduct. Report unacceptable behavior or security-sensitive concerns via the channels listed in [`SECURITY.md`](SECURITY.md).
